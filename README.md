# Grocery Time!

3人チームで制作したVR買い物シミュレーションゲームです。
限られた予算と時間の中で商品を選び、「必要なもの」と「欲しいもの」を判断しながら、予算管理を学ぶことを目的としています。

## Overview

プレイヤーはVR空間内のスーパーマーケットで買い物を行います。

買い物リストを確認しながら商品を探し、カートに入れ、最後にセルフレジで会計を行います。  
ゲーム終了時にはスコアや残金、選択した商品の正誤などが表示されます。

## Team

3人チームで約2か月間制作しました。

企画段階では全員でゲーム内容、ストーリーボード、世界観などを決め、その後、

- Design
- Environment
- Development

に役割を分けて制作しました。

## My Role

私はDevelopmentを担当しました。

Unity / C#を用いて、主に以下のシステムを実装しています。

- 買い物リストの生成・管理
- 商品取得
- カート制御
- 予算管理
- 制限時間
- セルフレジ
- 正誤判定
- スコア計算
- 結果表示
- リスタート処理
- ゲーム全体の進行管理

また、他メンバーが制作した3DモデルやUI、環境などをUnity上で統合し、各システムと接続して、一つのゲームとして成立させる役割も担当しました。

## Team Development

実際の開発に充てられた期間は約1か月で、全員が卒業研究や他の課題を並行して進めていました。

そのため、進捗や課題をこまめに共有し、Unity上で統合した際に素材不足や環境上の問題を発見した場合は、各担当に共有して追加・修正を依頼しながら実装を進めました。

担当を完全に分離するのではなく、必要に応じて互いにサポートしながら制作を進めました。
